# todo-api

## 액터
- 비로그인 사용자
- 로그인한 사용자

## 유스케이스 목록
1. 회원가입: 비로그인 사용자가 이메일과 비밀번호로 가입한다.
2. 로그인: 사용자가 로그인하고 토큰을 받는다.
3. 할 일 추가: 로그인한 사용자가 할 일을 추가한다.
4. 할 일 목록 조회: 로그인한 사용자가 내 할 일만 본다.
5. 할 일 완료/삭제: 로그인한 사용자가 내 할 일을 완료 처리하거나 삭제한다.

## 상세 명세: UC-2 로그인
- 액터: 비로그인 사용자
- 사전조건: 가입된 계정이 있다.
- 기본 흐름:
  1. 사용자가 이메일과 비밀번호를 보낸다.
  2. 시스템이 계정을 확인한다.
  3. 시스템이 토큰을 발급한다.
- 예외 흐름:
  - 이메일이 없거나 비밀번호가 틀리면 401 오류를 반환한다.
  - 필수 값이 비어 있으면 400 오류를 반환한다.
- 사후조건: 사용자는 토큰으로 다른 기능을 사용할 수 있다.

## 인증 규칙
- 토큰 없이 열린 주소: `GET /health`, `POST /users`(회원가입), `POST /auth/login`(로그인)
- 그 밖의 모든 주소는 헤더에 로그인 토큰이 있어야 한다.
  - `Authorization: Bearer <로그인 응답의 accessToken>`
- 토큰이 없거나, 위조됐거나, 만료됐으면 모두 같은 401 응답을 받는다.
  - `{"status":401, "error":"Unauthorized", "message":"로그인이 필요합니다."}`
- 토큰 유효 시간은 1시간이다. 만료되면 다시 로그인한다.
